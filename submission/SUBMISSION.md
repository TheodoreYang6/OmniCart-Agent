| 项目亮点 / 创新点 | **1. 从"问答"到"交易"的完整 Agent 闭环**：大多数 AI 导购只能做 Q&A，AI 和交易是割裂的。OmniCart 实现了自然语言驱动的完整购物闭环——"推荐蓝牙耳机"→ Agent 检索评分推荐 → "第二个加购"→ 解析指代+匹配 SKU 规格 → "下单"→ 读地址+订单汇总+持久化。独有的「问豆仔」功能支持对任一商品触发深度分析（用户口碑/FAQ覆盖/SKU建议/适用人群）和同类多维度对比表，分析后主动询问"要不要帮你直接下单"。7 种购物操作（加购/删除/改数量/清空/下单/改地址/确认）全部在 SSE 流式端点内自然语言驱动，不进 Agent Workflow 省延迟。<br><br>**2. 证据绑定的可解释推荐**：LLM 推荐容易产生"幻觉"——编造不存在的品牌和价格。OmniCart 从架构层面解决：所有推荐结论绑定 `evidence_ids`（营销/FAQ/评论/视觉/补充发现 5 类证据），每件商品产出 7 维分解分 + 各自权重 + 计算方法 + 支撑证据 ID，可逐条追溯到原文。四道幻觉防线（强制引用候选商品→65品牌白名单→价格校验→6s超时模板兜底）确保回答安全可靠。<br><br>**3. 闲聊与导购智能区分 + 三层记忆个性化**：传统方案要么只会推荐（用户说"你好"也硬推商品），要么只会聊天（聊完无法过渡到购物）。OmniCart 的 Router 可识别 30+ 种闲聊场景，先回应情绪再顺势引导购物（"饿了→推荐零食""无聊→推荐新奇好物"），用户随时切回导购模式，自然不割裂。三层记忆（短期约束继承+长期偏好条目化+会话历史持久化）配合 FollowUpEngine 7 种追问模式，实现越聊越懂用户的个性化导购。长期偏好支持自然语言输入→LLM自动解析→品类感知注入，无需填表单。 |
