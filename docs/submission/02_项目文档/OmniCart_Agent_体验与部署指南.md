# 欧米 · OmniCart Agent 体验与部署指南

本指南只说明可本地验证的体验方式。提交包不包含未验证的公网地址和 APK；请在本机或同一局域网内启动服务后使用 Android Studio 调试客户端。

## 1. 最快体验路径

### 启动后端

在仓库根目录准备 Python 环境和配置后启动服务：

```powershell
python -m pip install -r requirements.txt
python run.py
```

如果只需要验证基础对话链路，可按项目配置启用 Mock 模式再启动 FastAPI 服务。服务启动后访问：

```text
http://127.0.0.1:8006/api/health
```

需要完整检索与持久化能力时，再按仓库根目录 `README.md` 准备 PostgreSQL、Qdrant、Redis、模型密钥与商品索引（默认检索索引 `product_chunks_v9`）。

### 连接 Android 真机

1. 电脑与手机接入同一局域网；
2. 在 `android-client/app/build.gradle.kts` 的 Debug 配置中，将 `BASE_URL` 设置为电脑局域网 IP，例如 `http://192.168.x.x:8006/`；
3. 在 Android Studio 打开 `android-client`，选择已连接设备并运行 Debug；
4. 确认手机可访问 `http://<电脑局域网IP>:8006/api/health`。

不要在真机上使用 `127.0.0.1` 作为服务地址；它只指向手机自身。

## 2. 建议演示顺序

1. 打开“商品”页，浏览分类与商品详情；
2. 进入“欧米”对话页，输入“推荐一款 500 元以内、通勤降噪好的耳机”；
3. 观察阶段进度与首选商品卡先于文字回答到达；展开“再看看其他选择”；
4. 切换“深度思考”，输入带多项约束的需求，观察友好阶段而非内部推理；
5. 对一件商品点“问欧米”，确认聚焦分析卡出现、点击卡面可进入商品详情；
6. 点“与同类横向对比”，观察分栏对比卡与结论横幅，确认正文与卡片一致；
7. 登录后继续对话：让欧米把某商品加入购物车，确认购物车摘要卡与“去购物车结算”按钮；再说“下单”，确认订单预览卡与确认按钮，完成下单后观察订单结果卡与 LLM 收尾文案；
8. 切换深浅主题，确认卡片、标签和阶段进度均清晰可读。

## 3. 常见验证点

- 游客身份可完成一次性推荐，但购物车、订单和历史会提示登录；
- 多规格商品加购会出现规格选择卡，选择后直连加购；
- 断网或模型异常时，下单预览/成功应回退到确定性模板文案，不出现空回答。
