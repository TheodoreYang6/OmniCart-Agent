# OmniCart Agent

## 1. 项目简介

说明：

OmniCart Agent 是一个 Android 原生四 Tab 电商智能导购客户端，后端由 FastAPI Agent Runtime 提供多模态购物决策能力。

当前产品包含四个主页面：

1. 商品展示
2. 豆仔智能
3. 购物车
4. 个人中心

其中“豆仔智能”是核心 AI Agent 页面，负责多模态导购、商品推荐、证据解释、评分、Trace、Harness 展示，并可以通过受控 action 将商品加入购物车。

请强调：

- 本项目不是普通购物 App；
- 也不是单一聊天机器人；
- 而是一个具备完整购物链路的 Android 原生智能导购 Agent 产品。
